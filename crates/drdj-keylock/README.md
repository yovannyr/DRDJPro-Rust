# drdj-keylock

Worker-only whole-clip tempo processing preserving pitch, plus an allocation-free Rust correction stage for small dynamic changes. Connected to the desktop preparation/renderer path. Supports mono/stereo, 8–192 kHz and tempo 0.5–2.0. Input and output are independently capped at 67,108,864 interleaved samples; DSP internal allocations are additional. Never invoke whole-clip processing from the realtime callback. The adapter copies input, catches C++ exceptions, checks finite output and returns explicit errors.

Vendored implementation: Signalsmith Stretch and Signalsmith Linear as packaged in signalsmith-stretch 0.1.3, plus its interleaved C wrapper. Upstream licenses are retained in vendor; WRAPPER-LICENSE.md covers the Rust-package wrapper. Our bridge adds an exception boundary and hand-written minimal FFI, avoiding build-time libclang. cc compiles C++17; /Zc:__cplusplus is requested when supported on MSVC.

The synthetic stereo test checks duration, central-window zero-crossing frequency and channel polarity at 0.8 and 1.25 tempo. It does not qualify transients, arbitrary music, sound quality, runtime rate changes or hardware. Desktop jobs retain original source coordinates and replace the renderer on adoption. A Keylock reference supports Sync of a coupled-speed follower; Keylock targets support asynchronous one-shot tempo matching. The Rust micro module supplies bounded stereo-coherent overlap/add for +/-2% nudge on prepared audio. The same bounded correction stage supports continuous Keylock Sync following around a matched prepared base; desktop acquisition prepares that base asynchronously. Whole-track preparation is asynchronous; hard realtime and listening qualification remain open.

Micro correction tests cover +/-2% at 44.1/48/96 kHz, 50/110/440/1000-Hz tones, opposite stereo channels, RMS bounds and eventual bit-exact neutral return. These narrow signal tests do not establish general music/transient quality or hard realtime/device timing. Search is bounded and uses only inline state and a caller-provided immutable sampler.

A varying-correction test alternates +2/-2/+0.5/-0.5/0 percent every 33 ms and checks 440-Hz pitch and stereo polarity. The desktop verifies deadline expiry to neutral without GUI ticks and automatic follower acquisition/cancellation on both decks. Nominal source-clock alignment does not establish audible transient alignment.
