Decks and controllers

Load local music into A or B. Play, cue, pitch, loops and hot cues act on the selected deck. Check the audio output before playback.

REMOTE opens the generic display. USB / HID opens explicit device setup. Optional DVS requires a compatible build, input and explicit ARM; signal loss requires ARM again.

Build example

cargo test -p drdj-remote --locked

Hardware, visual and listening qualification remains a separate acceptance step.
