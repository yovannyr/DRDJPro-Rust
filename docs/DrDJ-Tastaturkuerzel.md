# Dr DJ – Tastaturkürzel

> **Hinweis:** Die beschriebenen Verknüpfungen beziehen sich auf eine US-Tastatur. Auf anderen Tastaturen können die Tastenpositionen unterschiedlich beschriftet sein.
>
> - `Strg` (Windows) entspricht `Command` (macOS)
> - `Alt` (Windows) entspricht `Option` (macOS)
>
> Wenn die Option **„Playback Keys Use Shift"** im Setup-Bildschirm aktiviert ist, erfordern alle Playback-Tasten zusätzlich `Alt` oder `Feststelltaste`.

---

## Wiedergabe (Playback)

| Aktion | Linkes Deck | Rechtes Deck |
|---|---|---|
| Gewählten Titel laden | `Shift` + `←` | `Shift` + `→` |
| Titel doppeln | `Strg` + `Shift` + `←` | `Strg` + `Shift` + `←` |
| Virtuelles Deck auswerfen | `Shift` + `Alt` + `←` | `Shift` + `Alt` + `→` |
| Play/Pause | `W` | `S` |
| Anspielrichtung umkehren | `Q` | `A` |
| Cue Point einstellen | `Strg` + `1, 2, 3, 4, 5` | `Strg` + `6, 7, 8, 9, 0` |
| Einstellen/Springen zu Cue Points im Titel | `1, 2, 3, 4, 5` | `6, 7, 8, 9, 0` |
| Cue Point löschen | `Shift` + `Strg` + `1, 2, 3, 4, 5` | `Shift` + `Strg` + `6, 7, 8, 9, 0` |
| Zum vorübergehenden Cue Point springen | `I` | `K` |
| Nächsten Titel laden | `Alt` + `W` | `Alt` + `S` |
| Vorherigen Titel laden | `Alt` + `Q` | `Alt` + `A` |
| Zurückspulen | `Alt` + `E` | `Alt` + `D` |
| Vorspulen | `Alt` + `R` | `Alt` + `F` |
| Pitch bend down | `T` | `G` |
| Pitch bend up | `Y` | `H` |
| Censor | `U` | `J` |
| Keylock | `F5` | `F10` |
| Record/Arm Flip | `\` | `\` |

## Loops

| Aktion | Linkes Deck | Rechtes Deck |
|---|---|---|
| Loop An/Aus | `[` | `'` |
| Autoloop An/Aus | `Alt` + `1, 2, 3, 4, 5` | `Alt` + `6, 7, 8, 9, 0` |
| Loop Roll | `Strg` + `Alt` + `1, 2, 3, 4, 5` | `Strg` + `Alt` + `6, 7, 8, 9, 0` |
| Slot Reloop | `Alt` + `[` | `Alt` + `'` |
| Loop in-Punkt einstellen/anpassen | `O` | `K` |
| Set/Adjust loop out point | `P` | `L` |
| Loop Slot Select Up | `Alt` + `O` | `Alt` + `L` |
| Loop Slot Select Down | `Alt` + `P` | `Alt` + `;` |

## Sample Player

| Aktion | Taste |
|---|---|
| Sample aus Bibliothek laden (Slot 1–6) | `Strg` + `Alt` + `Z, X, C, V, B, N, M, ,` |
| Sample abspielen (Slot 1–6) | `Z, X, C, V, B, N, M, ,` |
| Sample anhalten (Slot 1–6) | `Alt` + `Z, X, C, V, B, N, M, ,` |

## Bibliothek (Library Actions)

| Aktion | Taste |
|---|---|
| Titel nach oben/unten | `↑` / `↓` |
| Crates nach oben/unten | `Strg` + `Shift` + `↑` / `↓` |
| Markierung verschieben | `Tab` |
| Cursor bewegen, um zu suchen | `Strg` + `F` |
| Titel im Explorer (PC) oder Finder (Mac) zeigen | `Strg` + `R` |
| Zuletzt geladenen Titel suchen (erneut drücken für anderes Deck) | `Strg` + `L` |
| Alle auswählen | `Strg` + `A` |
| Laden des Titels rückgängig machen | `Strg` + `Z` |
| Titel/Crate löschen | `Strg` + `Entf` |
| Datei in den Papierkorb verschieben | `Strg` + `Shift` + `Entf` |
| Titel zur Vorbereitungs-Steuerung hinzufügen | `Strg` + `P` |
| Waveform Display zoomen | `+` oder `-` |
| Textgröße der Bibliothek zoomen | `Strg` + `+` oder `-` |
| Neue Aufnahme starten (Mikrofon, Aux oder mMx) | `Strg` + `N` |
| Offenen Titel im Standard-Media-Player öffnen | `Strg` + `O` |
| (Während BPM-Bearbeitung) Doppelter/Halber BPM | `Alt` + `↑` / `↓` |
| Beatgrid-Bearbeitungsmodus eingeben | `Alt` + `Leertaste` (wiederholen, um zwischen Decks zu wechseln) |
| Dr DJ verlassen | `Esc` (Escape) |
